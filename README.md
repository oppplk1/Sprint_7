Здание по проекту 7 спринта, API тестирование сервиса.

В проекте выполнены тесты: на создание заказа и курьера, на принятие заказа, на получение списка заказов, на получение заказа по номеру трека, на на логин курьера и на удаление курьера.

Отчеты по тестам сформированы и хранятся в папке allure_results.
